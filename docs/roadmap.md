# Roadmap

## Completed V1 Foundations

- Current Cook County parcel geometries can be fetched for Park Ridge PINs.
- Cook County Assessor improvement rows can be fetched and reduced to primary building records.
- Parcel Universe can filter the build to Park Ridge for a target assessment year.
- Address/PIN search exists for whatever parcel fields are available.

## Next Priorities

1. Add animation showing cumulative homes built by year.
2. Add true historical parcel layers by year.
3. Add recorded subdivision plat ingestion.
4. Add Cook County building permits.
5. Add Park Ridge permit data if available.
6. Add Sanborn map overlays.
7. Add georeferenced 1938/1939 aerial photography.
8. Add side-by-side swipe comparison between current parcels and historical imagery.
9. Add exportable neighborhood reports.
10. Add address enrichment from a public address dataset if available.
11. Add zoning overlay.
12. Add historic landmarks and 100-year-old homes overlay.
13. Add AI-generated neighborhood development summaries.
14. Add support for additional municipalities.
