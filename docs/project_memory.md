# Project Memory

## Future Hardening

- Home Ancestry media: HARGIS photo and PDF attachments are now carried through the parcel data and rendered in the property view. Next hardening step: sync those media files into durable storage, either Supabase Storage or local `public/` assets, so the app is not dependent on remote ArcGIS media URLs for long-term availability.
- Home Ancestry data completeness: separate every home-specific clue into four statuses: loaded, digitally available, request needed, and not public/restricted. The most important completeness push is a Source Sync system that prioritizes Park Ridge Historic Preservation/Granicus PDFs and 100-year-home records, Cook County recorder document index by PIN, durable PDF/photo/plan storage, and a FOIA/request workflow for plans, old permits, and historical building files. Keep the UI honest about which records are already attached versus which are known to exist but still need import, portal access, purchase, or a city/county records request.
- Home Ancestry public-history clues: the app now has optional imports for Park Ridge public case files, local-history directory breadcrumbs, and Sanborn map references. Next hardening step: collect real rows from city agendas/packets, library directory indexes, and rights-cleared Sanborn references, then populate `data/raw/park_ridge_design_review_cases.csv`, `data/raw/park_ridge_directory_breadcrumbs.csv`, and `data/raw/park_ridge_sanborn_snapshots.csv`.
- Street-bounded blocks: replace parcel-fabric fallback blocks with real block IDs from U.S. Census TIGER/Line tabulation blocks or Cook County street centerline-derived polygons. The pipeline now supports Census block joins when `data/raw/tl_2024_17_tabblock20.zip` is present.
- Home Ancestry product direction: continue treating a house like an individual with family context. Useful next concepts include Before/After Block Memory, Artifact Timeline expansion, "What Kind of Change Is This?" classifications, subdivision/plat family groups, and newspaper/local-history mention matching.
- Before/After Block Memory: at block, neighborhood, and city scale, show what existed then, what survived, and what changed using Sanborn maps, historical parcels, building footprints, HARGIS, permits, and photos.
- Change Story classifier: classify change as preservation, careful reinvestment, turnover, rebuild pressure, expansion, or dormant. Use the same vocabulary at property, block, area, and Park Ridge scale.
- Artifact timeline hardening: prioritize attaching source images, PDFs, Sanborn sheet references, directory breadcrumbs, city case packets, and historic survey records to timeline events rather than only showing them as separate evidence cards.
